# 미검증 — 직접 확인해야 하는 항목

이 프로토타입은 **합성 입력**과 **시뮬레이션**으로만 검증했습니다. 아래는 **실제 웹캠·사람·현장**이 있어야
확인 가능한 항목으로, 지금은 **미검증**입니다. 합성 테스트 통과가 이 항목들의 현장 안정성을 보장하지 않습니다.

## 실제 카메라 경로 (코드는 작성됨, 실기 미검증)

- MediaPipe 얼굴/손/포즈 랜드마커의 **실제 웹캠 프레임 처리** — 이 세션의 브라우저 프리뷰 창은 카메라 권한/장치가 없어 구동하지 못했습니다.
- **v2 Web Worker 인식 경로**(`workerSource`) — 빌드·타입·워커 청크 분리는 확인했으나, **실제 카메라로 ImageBitmap 전송→워커 추론→표시**까지는 실기 미검증. 워커 미지원 환경의 메인스레드 폴백도 실기 미검증.
- **v2 포즈 결합**(`usePoseFusion`) — 로직은 유닛 테스트/시뮬로 검증했으나, **실제 카메라에서 포즈 모델 부하와 손 귀속 정확도**는 미측정(부하가 커 기본 꺼짐).
- 랜드마크→관측치 변환(얼굴 bbox 크기, 손 열림 heuristic)의 **실제 정확도와 임계값 적정성**.
- 카메라 오류 분기(권한 거부 / 장치 없음 / 사용 중 / 연결 끊김)의 **실제 발생 시 동작** — 코드로 분기했으나 실장치로 재현하지 않았습니다.
- 조명·역광·해상도에 따른 검출 안정성.
- **지연 수치의 의미**: 운영자 패널의 ‘인식 지연/파이프라인 지연’은 **앱 내부 시각** 기준입니다. 실제 ‘움직임→화면 표시’ 지연은 카메라·디스플레이 지연을 포함하므로 [`FIELD_TEST_SHOOT.md`](FIELD_TEST_SHOOT.md)의 영상 계수법으로 별도 측정하세요.

## 현장 목표치 (사양 아님, 측정 필요)

[`FIELD_TEST_SHOOT.md`](FIELD_TEST_SHOOT.md)의 시나리오로 측정하세요.

- 무인 30초 동안 **오작동(잘못된 환영/하이파이브) 0회**.
- 1인 좌우 이동 10회에서 **방향 반전·시선 떨림** 육안 확인.
- 2인 교차 10회에서 **잘못된 대상 전환 횟수** 기록.
- 하이파이브 20회에서 **성공/실패/중복/타인 손 오발동** 기록.
- 선택 PC에서 **30분 연속** 실행: 정지·메모리 증가·카메라 복구 확인.
- **렌더 30 FPS↑, 반응 지연 200ms 이내**(초기 목표). 장비·조명·입력 해상도·측정법을 함께 기록.
  - 시뮬레이션 브라우저 기준 렌더/인식 FPS는 높게 나왔으나, **실제 카메라 + MediaPipe 부하 하의 FPS/지연은 측정되지 않았습니다.**
  - **앱 내부 처리시간**과 **실제 움직임→화면 표시까지의 지연**을 구분해 측정하세요(후자는 카메라·디스플레이 지연 포함).

## 알려진 한계 (초기 버전)

- **동일인 보장 없음**: track ID는 세션 내 임시값입니다. **완전 가림이나 두 사람의 완전 교차** 후 같은 사람을 보장하지 않습니다.
  v2의 **속도 예측 추적**이 교차 시 ID 스왑을 줄이지만 완전 겹침은 여전히 한계입니다. 얼굴 **생체 식별/재방문 인식은 의도적으로 넣지 않았습니다.**
- **손↔사람 귀속**: 기본은 거리·모호성 마진, v2에서 **포즈 결합**을 옵션으로 추가(손→포즈 손목→얼굴). 실기 정확도는 위 ‘실제 카메라 경로’ 참고.
- **Web Worker**: v2에서 구현(지원 시 오프로딩, 미지원 시 메인스레드 폴백). OffscreenCanvas 기반 렌더 오프로딩은 범위 밖.
- **Live2D 미연결**: 자산 미제공. [`LIVE2D_CHECKLIST.md`](LIVE2D_CHECKLIST.md) 참고.
- 시선은 얼굴 **위치** 기반 연출이며 **안구 시선 측정이 아닙니다**.
- 근접은 얼굴 크기 기반 **상대값**이며 **미터 거리가 아닙니다**.
- 익명 이벤트의 세션 수는 **고유 방문자 수/재방문율이 아닙니다**.
- 상용 배포용 SDK/모델 라이선스 조건은 [`ASSET_SOURCES.md`](ASSET_SOURCES.md)에 정리했고, **상용 조건 최종 확인은 별도 진행 필요**.
