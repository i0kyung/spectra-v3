# 운영자 가이드 — 설치 · 보정 · 운영

## 1. 설치

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

- `npm install` 후 `npm run dev`/`npm run build`가 자동으로 `scripts/fetch-models.mjs`를 실행해
  MediaPipe **WASM을 `public/wasm/`로 복사**하고 **얼굴/손 모델을 `public/models/`로 다운로드**합니다.
- 오프라인 설치가 필요하면, 인터넷이 되는 PC에서 한 번 실행해 `public/models/*.task` 두 파일을 만들어 그대로 복사하세요.

## 2. 카메라 시작

- 운영자 패널 → **카메라 시작**(또는 `C`). 브라우저가 권한을 물으면 허용합니다. **마이크는 요청하지 않습니다.**
- 카메라는 **보안 컨텍스트**에서만 열립니다: 개발 `http://localhost`(= `127.0.0.1`), 배포 **HTTPS**.
  파일을 더블클릭(`file://`)하면 브라우저가 카메라를 막습니다.
- 오류는 화면에 종류별로 안내됩니다: **권한 거부 / 카메라 없음 / 사용 중 / 연결 끊김 / 보안 컨텍스트 필요**.
  각각 조치 후 **다시 시작**을 누르거나 **시뮬레이션으로 전환**할 수 있습니다.

## 3. 체험 ROI 설정

- 미리보기 영상 **위에서 드래그**하면 체험 구역(ROI)을 다시 그립니다. ROI 안에서 일정 시간 머문 사람만 선택 후보가 됩니다.
- 미리보기는 셀피처럼 **좌우 반전**되어 보이며, 오버레이의 대상/후보 표시도 같은 기준으로 그려집니다.

## 4. 시선 보정 (가장 중요)

목표: **관람객이 화면 오른쪽으로 이동 → 캐릭터가 그 사람 쪽을 본다**가 되도록 맞추는 것.

1. **시뮬레이션**이나 카메라 상태에서 대상을 좌우로 움직여 봅니다.
2. 반대로 본다면 **좌우 반전** 체크를 토글합니다(카메라·시뮬 공통 설정).
3. 위아래가 반대면 **상하 반전**.
4. **시선 반응**(게인)으로 고개 돌리는 정도, **떨림 무시**(데드존)로 미세 떨림, **부드러움**으로 반응 속도를 조절합니다.

> 시선은 얼굴 **위치** 기반의 머리/몸 방향 연출입니다. 관람객의 **안구 시선을 측정하지 않습니다**.
> 눈·시선 방향을 정밀하게 확인하려면 렌더러를 **테스트글리프**로 바꾸세요(눈동자·정면 포인터가 뚜렷합니다).

## 5. 근접 · 타이밍

- **가까움 진입/이탈**: 얼굴 크기 기준의 상대 근접. 두 임계값이 달라 경계에서 깜빡이지 않습니다. (미터 거리 아님)
- **선택 대기(dwell)/놓침 유예(grace)/하이파이브 유지·쿨다운**: 모두 **초기 조정값**입니다. 현장 조명·렌즈·동선에 맞춰 바꾸세요.

## 6. 렌더러 · 표정 · 조명

- **Sprite**: 재사용 PNG 캐릭터(실사용). **테스트글리프**: 방향 검증용 코드 캐릭터(‘테스트 캐릭터’ 표기).
- 표정: **자동**(상태 연동) 또는 수동 고정. 시그니처 컬러는 태그 인식 시 공간 조명 연출 시연입니다.

## 7. 익명 이벤트 (선택)

- 기본 **꺼짐**. **집계 사용**을 켠 경우에만 로컬에 임시 세션 ID·시작/종료·하이파이브 횟수가 쌓입니다.
- **보관 기간(일)**을 지나면 자동 삭제, **전체 삭제** 버튼으로 즉시 비웁니다. JSON/CSV로 내보낼 수 있습니다.
- 이 값은 **익명 세션 수**이며, **고유 방문자 수나 재방문율이 아닙니다.**

## 8. 발표/키오스크 운영

- `F` 또는 **발표 모드**로 운영자 패널을 숨겨 관람객 화면만 남깁니다.
- **설정 저장**으로 현재 보정값을 브라우저에 저장하고, **초기화**로 기본값으로 되돌립니다.
- 장시간 운영 시 디스플레이 절전/화면보호기를 끄세요. 탭이 백그라운드가 되어도 워치독이 상태를 유지하지만, 실제 렌더는 화면이 켜져 있어야 합니다.

## 9. 단축키

`F` 발표 모드 · `Space` 시뮬 하이파이브(누르는 동안 손) · `C` 카메라 시작
